# GAL Technology PLC — Updated Website

## Included
- Eight responsive pages: Home, About, Products, Services, Partners, Testimonials, News, and Contact.
- English and Amharic language selector with saved preference.
- Responsive navigation, cookie preference controls, product search/filter/sort, and contact-form demo feedback.
- Supplied laboratory photographs integrated into the homepage, About, Products, Services, and News pages.
- Expanded, professionally written “Why GAL Technology” section.

## Run the website
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, run the folder through a simple local web server. The Google Fonts stylesheet requires an internet connection; the site content and images are local.

## Edit the website
- Main styles: `css/style.css`
- Shared interactions: `js/main.js`
- Product catalog entries: `js/products.js`
- English and Amharic wording: `js/translations.js`
- Images: `assets/images/`
